# 可选择的研究叙事模式

以下是归纳的组织方法，不是作者宣称的写作策略，也不是获奖原因的因果结论。

| 入口 | 论证主线 | 必要证据 | 容易写错 |
|---|---|---|---|
| 失败诊断 | 已有成功 → 特定条件失效 → 可检验解释 → 定向修复 | 可靠复现、竞争解释、干预、恢复效果 | 用几个例子证明普遍失效 |
| 约束改变 | 旧目标合理 → 实际预算/硬件/精度不同 → 新目标 → 匹配设计 | 真实约束、同预算对照、质量成本曲线 | 以数学精度替代任务收益 |
| 新监督来源 | 昂贵/缺失标签 → 可利用信号 → 验证信号 → 新能力 | 信号准确性、污染检查、同数据对照 | 把弱标签当真值或宣称零成本 |
| 表示瓶颈 | 下游困难 → 表示无法保留关键信息 → 新表示 → 系统收益 | 表示重建/保真、分离模型容量影响、下游验证 | 用端到端分数替代表示证据 |
| 最小理论模型 | 复杂现象 → 保留关键结构的简化 → 定理/预测 → 适用边界 | 假设、证明、可检验预测、失效区间 | 把玩具模型结论外推所有深网 |
| 重新定义评价 | 常用代理 → 遗漏真实目标 → 新定义/指标 → 决策变化 | 构念效度、对照案例、替代解释 | 只有批评，没有可操作评价 |
| 能力与资源 | 原来做不到/成本过高 → 可复用资源/系统 → 新可达范围 | 系统测试、组件/数据质量、使用成本 | 强行编造机制发现 |
| 立场与治理 | 通行假设 → 被遗漏的利益/风险 → 证据与反方 → 可行行动 | 可追溯事实、价值前提、权衡 | 将规范主张写成实验结论 |

## 如何选

如果最强证据是一个稳定失效现象，先写诊断，不强把新模块当中心。若优势只有特定预算下成立，把预算写进问题定义。若主要贡献是数据/表示，把“数据怎样可靠”“表示保存了什么”放在大模型结果之前。理论论文先明确需要证明哪些不同命题，不用一张拟合曲线替代证明。

候选主线的排序依据是证据强度、认知增量、读者能否验证、边界是否清晰；不是标题是否震撼。不要用任意数字评分制造客观性。

## 原文案例及可迁移操作

- [Polar Express](https://arxiv.org/html/2505.16932)：把有限计算与数值条件纳入算法目标。可迁移操作：在提出方法前说明何种资源条件改变了最优选择。
- [Revela](https://arxiv.org/html/2506.16552)：从现有学习信号中构造检索能力。可迁移操作：区分“没有任务标签”与“没有训练数据/成本”。
- [TRELLIS.2](https://arxiv.org/html/2512.14692)：先处理几何与材质表示，再考察生成。可迁移操作：给中间表示自身安排独立证据。
- [Grokking in Ridge Regression](https://arxiv.org/html/2601.19791)：将看似单一现象拆成早期拟合、持续泛化差、后期泛化三个证明任务。可迁移操作：把中心现象拆到不能互相替代的命题。
- [Obfuscation Atlas](https://arxiv.org/html/2602.15515)：检测分数变化不自动等于目标行为改善。可迁移操作：固定输出或评估对象，检查测量工具变化造成的假象。

同一论文可跨多种模式。不要照搬作者术语、故事顺序或未经复核的数值到用户的新研究。
